# go-musicfox v5.1.0

## 1. 网页登录（macOS / Windows / Linux）

全新的「网页登录」入口：弹出原生浏览器窗口加载网易云网页版登录页面，通过原生 Cookie API 每 ~1 秒轮询检测登录 Cookie（`MUSIC_U`，HttpOnly 属性，`document.cookie` 无法读取），拿到后自动完成登录校验，**三平台均已支持**。

### 平台实现

- **macOS**：WKWebView 原生窗口（purego + objc 桥接，无 CGO），非持久化数据存储（内存不落盘，不留痕）；窗口显示期间自动切换应用激活策略，所有退出路径（成功 / 用户关窗 / 取消）均恢复
- **Windows**：WebView2 原生窗口（Win11 自带 Runtime），单 UI 线程模型承载建窗、环境创建与 Cookie 轮询；使用 13thgoutham/go-webview2 fork，修复了新版 Go 编译回调参数限制导致的启动 panic
- **Linux**：WebKitGTK 原生窗口（purego 直调，零 CGO），运行时优先加载 6.0 栈，自动回退 4.1 / 4.0 旧版 API，覆盖 Debian 11/12、Ubuntu 22.04 等旧发行版；无 DISPLAY/WAYLAND_DISPLAY 时自动降级

### 不可用降级

- **入口自动隐藏**：WebView 检测不可用时（非三平台、Linux 缺少 WebKitGTK 运行库、Windows 缺少 WebView2 Runtime），Login 页「网页登录」按钮自动隐藏，鼠标 / 键盘导航同步跳过，不残留无效入口
- **错误提示兜底**：窗口打开失败时（如 GTK 初始化失败）页面显示明确错误信息，而不是静默失败
- **诊断日志**：Linux 库加载失败时输出 dlopen 诊断日志，便于排查缺失的运行库

## 2. 崩溃诊断与日志

- **崩溃记录**：panic / 崩溃自动写入日志文件，并附带上报提示信息，便于反馈问题
- **Windows 控制台恢复**：Windows 下异常退出后正确恢复控制台状态与崩溃日志
- **超大日志截断**：日志文件超过大小限制时直接截断而非重命名为 `.old`，避免日志丢失
- **原生库优雅降级**：MediaPlayer / UserNotifications / WebKitGTK 等框架加载失败时静默降级——对应功能（Now Playing 远程控制 / 系统通知 / 网页登录）自动禁用，不影响主应用启动

---

## 3. 渲染与性能优化

- **渲染帧率限制**：限制 UI 渲染频率，消除每帧渲染开销（渲染器输出缓存、背景缓存等），高刷新率下 CPU 占用显著下降
- **频谱渲染器重构**：频谱 / 声谱图 / 示波器 / 李萨如渲染器全面重构，支持更多渲染模式与更稳定的性能
- **按墙钟时间滚动**：声谱图与歌词滚动速度不再随帧率变化（修复 60 FPS 下滚动速度是 5 FPS 的 12 倍的问题）
- **封面渲染优化**：Kitty 封面图渲染优化——透明背景下封面渲染在文本下层、弹窗自然遮挡（无需碰撞检测），背景透明度变化时自动失效缓存重新渲染
- **MPRIS 节流**：Linux 下 MPRIS 状态更新节流，避免频繁 D-Bus 调用
- **滚动条优化**：横向滚动条渲染优化

---

## 4. 播放器稳定性修复

- **MPV**：命令连接增加排空 goroutine，防止 mpv 发送缓冲堆积导致卡死；切歌增加 file-loaded 超时 watchdog 兜底（#615）
- **Beep**：修复播放期间进度与时间持续落后于真实播放进度的问题（#611）
- **Beep**：修复切歌时 timer 与 streamer 的数据竞态（可能导致 nil 接口 panic）
- **频谱**：修复 oscilloscope / vectorscope 在高渲染帧率下的采样数据竞态损坏
- **计时器**：Timer 字段并发访问竞态修复（`-race` 回归测试覆盖）

---

## 5. 其他修复与优化

- **FLAC 下载**：修复 FLAC 格式下载缺少专辑封面的问题（#606）
- **二维码登录**：优化二维码登录请求——模拟 Chrome TLS ClientHello 指纹并附带完整浏览器请求头，规避服务端对非浏览器客户端的反爬检测（462 风控）
- **退出死锁**：修复退出确认后界面死锁问题
- **封面渲染**：修复取消渲染时 goroutine 卡死问题
- **Last.fm 授权页面**：重构支持鼠标交互（hover / 点击），与其他自定义页面体验一致
